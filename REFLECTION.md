# Week 1 Reflection

1. What is the difference between building a UI imperatively (plain DOM code) and
declaratively (React)?

- Plain DOM code does not support reusability, making it a hassle when modifying a components throughout the project.

2. Why must a component name start with a capital letter?

-  React component is distinguished from other HTML components, therefore it needed to be capital letter.

3. What does a fragment <>...</> do, and why not just use a <div>?

- The fragment denotes the opening and closing of HTML elements, allowing for the document parser to understand when the element begins and ends, allowing for better layout control. 

4. Name one benefit of splitting the UI into small components.
 
- Small components increase the maintainability of the system and allow the division of work in collaborative environment.
